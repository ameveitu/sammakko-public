# Julkaisuaineiston lähteet

Kotisivu on hakemistossa `kotisivu/`, whitepaper hakemistossa `whitepaper/`, oppimisverkko hakemistossa `oppimisverkko/` ja oppituntien lähteet hakemistossa `oppitunnit/`. Jaettu navigointi on hakemistossa `shared/`. Alkuperäiset Aavan ja Loikan kuvat tulevat Liten resursseista.

Koottu palvelinsivusto syntyy hakemistoon `.build/site/`. Palvelimelle vietävä paketti asetuksineen syntyy hakemistoon `.build/server/`. [Toimitusohje](../docs/DELIVERY_FI.md)
