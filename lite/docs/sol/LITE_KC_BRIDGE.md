# Sammakko Lite – KC bridge for Sol (adapter contract v1)

Lite is the `lite` adapter. Sol's repo is not in this workspace, so this file is the whole handoff.
Nothing here says that Lite is deployed or that pupils can reach it.

## Route (the only supported form)

    <lite base URL>#kc/<encodeURIComponent(canonical KC id)>

Example: `…/index.html#kc/M-TH-08`. The base URL is whatever document Lite is served from.
Lite has none configured: `deployment.baseUrl` in the manifest is `null`.

## Availability manifest

`lite-runtime.json` sits next to `index.html` in the build. It is generated by `tests/v4.test.ts`,
and the test fails if it drifts from the build. Read these fields:

| field | meaning |
|---|---|
| `schema` | `sammakko-lite-runtime/1` |
| `route.template`, `route.version` | route syntax (v1) |
| `build.contentRev`, `build.graphSha256`, `build.canonicalSha256` | content and graph revision the ids belong to |
| `runtimeAvailability.ids` | the 181 KC ids this build can open |
| `runtimeAvailability.lessonRev` | per-lesson content revision |
| `deployment.*` | `baseUrl: null`, `endpointVerification: not_configured`, `studentReachability: unverified` |

The resolver should treat a KC as linkable only when **all** of these hold:

1. the id is in `runtimeAvailability.ids`;
2. `build.canonicalSha256` matches Sol's canonical graph;
3. a base URL has been configured and checked by whoever deploys the app.

Until (3) holds, show the link as a preview, not as a pupil route.

## What Lite does with a link

- **Known id:** opens the lesson in its normal mode. No new prerequisite locks; preview and free jumps work as before.
- **Canonical id not in this build:** shows "Aihetta ei ole tässä versiossa" with the canonical title. Nothing opens.
- **Unknown or malformed id:** shows "Linkki ei toimi" or "Tunnusta … ei löydy". Nothing opens.
- **Title list:** the titles of ids that are not in Lite come from `canonical-ids.json`, a static file next to `index.html`. It is fetched only for such ids.
- **Title list not loaded** (network, HTTP error, timeout of 10 s, bad shape): shows "Aiheluetteloa ei saatu ladattua" with "Yritä uudelleen" and "Kartalle". This is never reported as an unknown id. A late answer for an address the reader has already left is ignored.
- **Recording:** opening, reloading or copying a link records no attempt, inference or reward.
- **Navigation:** works on the first load, on reload and on an address change (`hashchange`).
  - Changing the address stops the running lesson, including its animations and sounds.
  - "Kartalle" clears the hash, so Back and Forward follow the browser history.

## Resolver states Sol may show (suggested)

| state | condition |
|---|---|
| `available` | id in the manifest, base URL configured and verified |
| `build_only` | id in the manifest, no verified base URL |
| `not_in_lite` | canonical id, not in the manifest |
| `revision_mismatch` | `canonicalSha256` differs from Sol's graph |

## Limitations

- Lite has no server. Progress is stored per browser in `localStorage`, so a link does not carry a pupil's identity.
- The adult view's copy button gives the link for the current page. On `localhost` it says the link works only on that machine.
